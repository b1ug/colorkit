# colorkit

Opaque RGB and HSV values, CSS color names, and Hex conversion for Go.

This repository is under development. No versioned release is published yet.

The implementation targets Go 1.13 source compatibility, uses only the standard
library, and performs no device, file, environment, or network access. Current
maintained Go releases are used for development and delivery.

The color package is independent of blink(1), blink1-go, and nb1. Those projects
will adopt a validated, tagged colorkit version after the package is complete.
